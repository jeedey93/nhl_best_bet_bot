Rules
32 picks required — you must assign a prospect to every first-round slot before submitting. Use auto-fill to complete any gaps.
One entry per name — re-submitting with the same name overwrites your previous picks. Update freely before draft night.
Top 50 prospects only — all picks must come from the official pool big board. Each prospect can only be assigned to one slot.
Max score is 128 pts — 32 picks × 4 points for a perfect board. Scores are calculated after draft results are entered on June 27.
Scoring is prospect-based — points are awarded based on where you predicted a prospect would be picked, not which team you assigned them to.

Draft starts June 27 — submit your picks before then
